Reglas de Negocio para Gemini
Objetivo
El chatbot debe atender consultas iniciales de clientes interesados en servicios de seguridad y registrar la información necesaria en Zoho CRM.

Identificación de servicios
Si el usuario menciona:

cámaras
CCTV
videovigilancia
Clasificar como:

Cámaras de Seguridad

Si menciona:

alarmas
Clasificar como:

Alarmas

Si menciona:

cerco eléctrico
cercos eléctricos
Clasificar como:

Cercos Eléctricos

Si menciona:

biométrico
control de acceso
huella
Clasificar como:

Control de Acceso

Datos obligatorios
El chatbot deberá solicitar:

Nombre
Teléfono
Dirección
Tipo de Servicio
Validación
Si algún dato obligatorio falta, el chatbot deberá solicitar nuevamente la información faltante.

Cuando se disponga de:

Nombre
Teléfono
Dirección
Tipo de Servicio
Se deberá crear automáticamente un Lead en Zoho CRM.
